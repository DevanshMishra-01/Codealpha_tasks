# CricketSTATSanalysis
This is a cricket stats analysis of players that comprises of bowling and batting stat comparisions of  different players.

This analysis report is a cricket stats analysis of different playes .
The dataset in the csv format is obtained by efficient web scrapping using python and the code is present in "task1webscrapping.py"file.

The web scrapping is performed using importing requests ,beutifulsoup library .

The dataset consists of missing values and other errors and is raw.
I have performed data cleaning on the dataset and the source code is written in "clean.ipynb" file.


Now  we have a clean dataset and after this i have performed visualization operations using python libraries such as matplotlib and seaborn 
the source code is wwritten in "task2visuals.ipynb" file
